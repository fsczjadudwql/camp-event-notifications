## Overview

Camp Event Notifications is a Baldur's Gate 3 mod that displays a subtle UI notification whenever a camp-triggered companion cutscene, approval event, or story moment is ready to view, preventing players from missing critical companion relationship events by forgetting to return to camp between adventure sessions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Camp Event Notifications** delivers the features you need in a clean, intuitive package.

> Official website: [nexusmods.com](https://nexusmods.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Event Alerts** | Notification badge when new camp cutscenes or events are available |
| **Companion Tracking** | Tracks pending approval events for all active companion relationships |
| **Non-Intrusive UI** | Small indicator overlaid on existing UI — does not interrupt gameplay |
| **Quest Integration** | Alerts for story-critical camp moments tied to main quest progression |
